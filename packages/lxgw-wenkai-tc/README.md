# LXGW WenKai TC webfont

`@vp-tw/cjk-web-fonts-lxgw-wenkai-tc` contains LXGW WenKai TC v1.522 as
Unicode-range WOFF2 subsets. It includes proportional and monospaced families
in Light 300, Regular 400, and Medium 500 weights.

## CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-lxgw-wenkai-tc@0.0.1/dist/index.css"
/>
```

Use `LXGW WenKai TC` for the proportional family and `LXGW WenKai Mono TC` for
the monospaced family.
