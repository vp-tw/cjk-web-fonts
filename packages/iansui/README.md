# Iansui webfont

`@vp-tw/cjk-web-fonts-iansui` contains Iansui v1.020 as Unicode-range WOFF2
subsets. Iansui is adapted from Klee One for Taiwan Traditional Chinese
educational forms.

## CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-iansui@0.0.1/dist/index.css"
/>
```

Use the CSS family name `Iansui` at weight 400.
