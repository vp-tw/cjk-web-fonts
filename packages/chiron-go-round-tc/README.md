# Chiron GoRound TC webfont

`@vp-tw/cjk-web-fonts-chiron-go-round-tc` contains Chiron GoRound TC v1.011 as
a variable webfont across weights 200–900 using the official Unicode-range
WOFF2 assets.

## CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-chiron-go-round-tc@0.0.1/dist/index.css"
/>
```

Use the CSS family `Chiron GoRound TC WS`.
