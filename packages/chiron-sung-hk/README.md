# Chiron Sung HK webfont

`@vp-tw/cjk-web-fonts-chiron-sung-hk` contains Chiron Sung HK v1.024 variable
webfonts with normal and italic styles across weights 200–900. The official
Unicode-range WOFF2 assets preserve the optical Text forms.

## CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-chiron-sung-hk@0.0.1/dist/index.css"
/>
```

Use the CSS family `Chiron Sung HK WS`.
