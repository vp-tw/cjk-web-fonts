# Wêlai Glow Sans TC Wide webfont

`@vp-tw/cjk-web-fonts-glow-sans-tc-wide` contains the wide-width Traditional
Chinese fonts from Wêlai Glow Sans v0.93 as Unicode-range WOFF2 subsets. It
includes nine weights from Thin 100 through Heavy 900.

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-glow-sans-tc-wide@0.0.1/dist/index.css"
/>
```

```css
body {
  font-family: "Glow Sans TC", sans-serif;
  font-stretch: extra-expanded;
}
```

Upstream: <https://github.com/welai/glow-sans>. Font license: SIL Open Font
License 1.1. Generated with `font-splitter v0.2.2` using a maximum bucket size
of 4,096 codepoints. The npm package contains CSS and WOFF2 assets only.
