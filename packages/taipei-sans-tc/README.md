# Taipei Sans TC webfont

Taipei Sans TC Beta 1.000 split into WOFF2 files with Unicode ranges. The
package includes light (300), regular (400), and bold (700) weights under the
web family name `Taipei Sans TC`.

## CDN

```html
<link
  rel="stylesheet"
  href="https://cdn.jsdelivr.net/npm/@vp-tw/cjk-web-fonts-taipei-sans-tc@0.0.1/dist/index.css"
/>
```
